# IAM-01 — Multi-Factor Authentication (MFA)

## Control Objective
Ensure all privileged and standard user accounts are protected with multi-factor authentication to reduce the risk of credential compromise.

---

## Configuration Summary
- Microsoft Entra ID used as Identity Provider
- MFA enforced using Microsoft Authenticator
- Backup admin account protected
- Per-user MFA used due to licensing constraints
- Authenticator app successfully registered
