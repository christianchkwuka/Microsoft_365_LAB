# Microsoft 365 / Entra ID – IAM GRC Lab

This repository documents an enterprise-style Microsoft 365 / Entra ID lab
focused on Identity & Access Management (IAM) controls.

## Scope
- Microsoft Entra ID (Azure AD)
- Identity & Access Management (IAM)
- MFA enforcement
- Admin roles & least privilege
- Audit logging & evidence
- ISO 27001 / NIST / BSI mapping

## Standards Mapping
- ISO/IEC 27001
- NIST SP 800-53
- BSI IT-Grundschutz

## Structure
- docs/ → Control documentation
- evidence/ → Screenshots & logs
- templates/ → Audit templates & mappings
