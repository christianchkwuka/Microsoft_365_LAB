# Microsoft 365 / Entra ID – Identity & Access Management (IAM) GRC Lab

## 📌 Overview
This repository documents a hands-on Microsoft 365 / Microsoft Entra ID lab focused on **Identity and Access Management (IAM)** controls.  
The lab simulates a **real enterprise environment** with department-based access control, multi-factor authentication (MFA), logging, and audit-ready evidence.

The objective is to demonstrate **practical IAM implementation** aligned with:
- ISO/IEC 27001
- NIST SP 800-53
- BSI IT-Grundschutz

All configurations are validated using **real sign-in logs and audit evidence**, not only configuration screenshots.

---

## 🏗 Architecture Summary
- Identity Provider: Microsoft Entra ID (Azure AD)
- Users: HR, IT, Finance, Sales, Management
- Access Model: Role-Based Access Control (RBAC)
- Authentication: MFA using Microsoft Authenticator
- Monitoring: Entra ID Sign-in Logs
